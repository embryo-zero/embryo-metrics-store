# Embryo Metrics Store

Embryo Metrics Store is Embryo-Zero's fork of [VictoriaMetrics](https://github.com/VictoriaMetrics/VictoriaMetrics) (7608f2c, commit 7608f2c). It does long-term metrics storage.
